# Демо-диалог

Данные синтетические.

```text
Клиент:
Кондиционер Haier не охлаждает. Зеленоград, корпус 458.

Бот:
Услуга: диагностика кондиционера, который не охлаждает
Адрес: Зеленоград, корпус 458
Предварительная стоимость: от 1500 ₽

Выберите удобное время:
[15.07 14:00–16:00]
[15.07 17:00–19:00]
[16.07 10:00–12:00]
[Нужен другой вариант]

Клиент:
нажимает 16.07 10:00–12:00

Бот:
Проверьте заявку:
Услуга: диагностика кондиционера, который не охлаждает
Адрес: Зеленоград, корпус 458
Время: 16.07 10:00–12:00
Предварительная стоимость: от 1500 ₽
Слот удерживается 10 минут.

[Подтвердить]
[Выбрать другое время]
[Изменить данные]
[Отменить]

Клиент:
нажимает «Подтвердить»

Бот:
Заявка №REQ-000005 принята.
Сотрудник свяжется с вами.
```

## Изменение существующей заявки

```text
Клиент:
Хочу поменять дату одной из моих заявок.

Бот:
Запрос на изменение оформленной заявки передан сотруднику.

Оператор:
получает список активных заявок клиента, адреса, время и стоимость.
```

## Unsafe

```text
Клиент:
Розетка возле кондиционера искрит.

Бот:
просит не включать оборудование, при возможности обесточить его
и передаёт обращение сотруднику.
```
