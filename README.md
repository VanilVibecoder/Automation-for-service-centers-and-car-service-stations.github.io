# Сайт для демонстрации услуг по автоматизации на n8n

## Описание
Этот сайт создан для демонстрации услуг по автоматизации бизнес-процессов для сервисных центров с использованием n8n. Сайт представляет собой портфолио работ и описание услуг, которые помогают сервисным центрам автоматизировать обработку заявок, интегрировать различные каналы коммуникации и улучшить взаимодействие с клиентами.

## Особенности
- Минималистичный дизайн
- Адаптивная верстка
- Плавные переходы
- Форма обратной связи с валидацией
- Мобильное меню
- Анимации при скролле

## Технологии
- HTML5
- CSS3
- JavaScript (ES6+)
- Responsive Design
- Cross-browser compatibility

## Установка и запуск
1. Склонируйте репозиторий
2. Откройте файл `index.html` в браузере

## Тестирование на различных устройствах
Сайт был протестирован на следующих разрешениях:
- Desktop: 1920x1080, 1366x768
- Tablet: 1024x768, 768x1024
- Mobile: 375x667, 414x896, 360x640

Для тестирования адаптивности используйте инструменты разработчика в браузере (F12) и переключайтесь между различными пресетами устройств.

## Структура проекта
- `index.html` - основная HTML-страница
- `styles.css` - стили сайта
- `script.js` - JavaScript-функциональность
- `favicon.ico` - иконка сайта
- `robots.txt` - настройки для поисковых роботов
- `sitemap.xml` - карта сайта
